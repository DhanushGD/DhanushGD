## 🌟 About Me

<p align="center">
  <sub>🧠 LLMs · 🤖 Agents · 📚 RAG · 🔗 MCP &amp; A2A · ⚙️ MLOps</sub>
</p>

I'm an AI Engineer who likes building the whole stack behind a language model — from the data pipeline that feeds it, to the fine-tuning run that shapes it, to the retrieval and agent layer that makes it useful, to the monitoring loop that keeps it honest in production.

- 🧠 **LLM fine-tuning & alignment** — SFT, LoRA/QLoRA, domain-adaptive pretraining (DAPT), and RLHF via PPO/DPO. I enjoy taking small open models (TinyLlama, Gemma, Llama) and making them genuinely good at one narrow thing.
- 📚 **Retrieval & search** — Hybrid, Graph, and Agentic RAG; hybrid BM25 + vector search with Vespa AI; embedding fine-tuning for domain-specific retrieval; grounding and hallucination measurement with RAGAS.
- 🤖 **Agentic systems** — multi-agent workflows with LangGraph and CrewAI, guardrails and human-in-the-loop checkpoints, and agent/tool interoperability across languages via MCP and A2A.
- ⚙️ **MLOps & closed-loop infrastructure** — drift detection, automated retraining, data validation gates, model registries, and blue/green deploys on AWS SageMaker, so models improve without someone babysitting them.
- 🔬 **Evaluation-first mindset** — I'd rather ship a measured 83% than an unmeasured "it looks good"; golden sets, LangSmith tracing, and CI-gated eval pipelines are part of how I build.

**What I care about:** the parts that make AI actually trustworthy — grounding, evaluation, drift monitoring, and keeping a human in the loop where it matters. My open-source projects explore the same themes: healthcare LLM alignment (DAPT → SFT → DPO), cross-language agent interoperability (MCP + A2A), and self-healing MLOps.

🎓 Integrated M.Tech in Software Engineering, Vellore Institute of Technology · 📍 Chennai, India
